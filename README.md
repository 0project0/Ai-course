# 🎬 دليل استخدام وإدارة موقع كورس الذكاء الاصطناعي (خاص بـ Sheren)

أهلاً بكِ أخصائية الذكاء الاصطناعي **Sheren**! 👋
هذا الموقع تم تصميمه وبرمجته خصيصاً لكِ لعرض كورس **صناعة وتعديل الفيديوهات بالذكاء الاصطناعي** بأعلى دقة وأنسب مظهر عصري، مع تفعيل حماية كاملة ضد سرقة وتنزيل وتسجيل الفيديوهات.

---

## 📁 بنية ملفات الموقع

الموقع مصمم بشكل خفيف وسريع جداً ويتكون من الملفات التالية:

- **`index.html`**: الصفحة الرئيسية للكورس وبنية المشغل والمحتوى.
- **`styles.css`**: ملَف التنسيقات والألوان والأشكال النيون وتأثيرات الحماية.
- **`app.js`**: المحرك البرمجي للمشغل المخصص ومحرك الحماية والتحكم بالدروس.
- **`videos-data.js`**: **(الملف الأهم لكِ)** - الملف الذي يحتوي على قائمة الوحدات، الدروس، وروابط الفيديوهات والمرفقات.
- **`README.md`**: هذا الدليل الشامل.

---

## 🎥 كيفية إضافة وفيديوهاتكِ الخاصة فور تجهيزها؟

الموقع حالياً مجهز بـ **فيديوهات تجريبية عالية الجودة** لتجربة الموقع وتصفحه فوراً.
عندما تجهزين فيديوهاتكِ المسجلة، اتبعي إحدى الطريقتين التاليتين لإضافتها:

### 🌟 الطريقة الأولى: وضع الفيديوهات داخل مجلد الموقع (الأسهل)
1. قومي بإنشاء مجلد جديد باسم `videos` داخل مجلد الموقع.
2. أنقلي ملفات الفيديوهات المسجلة إلى مجلد `videos` وسميها مثلاً (`lesson1.mp4`, `lesson2.mp4` ... إلخ).
3. افتحي ملف **`videos-data.js`** بواسطة أي محرر نصوص (مثل Notepad أو VS Code).
4. غيّري سطر `videoUrl` الخاص بكل درس إلى اسم ملف الفيديو:
   ```javascript
   videoUrl: "videos/lesson1.mp4",
   ```

### 🌟 الطريقة الثانية: استخدام روابط فيديوهات مباشرة من سيرفر خارجي
إذا كانت فيديوهاتكِ مرفوعة على سيرفر استضافة أو منصة فيديو تدعم الروابط المباشرة (`.mp4`)، يمكنكِ فقط وضع الرابط المباشر في `videoUrl`:
   ```javascript
   videoUrl: "https://your-server.com/path-to-video.mp4",
   ```

## 📝 إضافة وحدات أو دروس جديدة أو تعديل العناوين

داخل ملف **`videos-data.js`**، يمكنكِ تعديل أي نص بسهولة:
- **عنوان الدرس**: تعديل `title`
- **مدة الدرس**: تعديل `duration` (مثلاً: `"12:30"`)
- **وصف الدرس**: تعديل `description`
- **المرفقات (PDF أو أدوات AI)**: تعديل قائمة `resources` لإضافة أي روابط أو ملفات.

مثال لدرس:
```javascript
{
    id: "lesson-1-1",
    title: "1. مقدمة الكورس والتعرف على أدوات الذكاء الاصطناعي",
    duration: "08:15",
    videoUrl: "videos/lesson1.mp4",
    description: "في هذا الدرس نشرح الأسرار الأساسية لتشغيل أدوات الذكاء الاصطناعي...",
    resources: [
        { name: "🔗 رابط أداة Midjourney", url: "https://midjourney.com" }
    ]
}
```

## 🛡️ مميزات الحماية والتأمين المفعلة في الموقع

1. **مشغل فيديو مخصص (Custom HTML5 Player)**:
   - يخفي خيارات التنزيل الافتراضية التابعة للمتصفح.
   - لا يتيح زر "حفظ الفيديو باسم..." أو الوصول للرابط المباشر بسهولة.
2. **منع الزر الأيمن (Right-Click Block)**:
   - حظر القائمة المنسدلة على كافة أنحاء الموقع وعناصر الفيديوهات.
3. **حظر اختصارات الفحص والسرقة**:
   - حظر `F12`, `Ctrl+Shift+I`, `Ctrl+Shift+J`, `Ctrl+U` (عرض سورس الصفحة), `Ctrl+S` (حفظ الصفحة).
4. **حماية تسجيل الشاشة والشاشات الخارجية (Screen Protection Shield)**:
   - عند محاولة تسجيل الشاشة أو الانتقال لنافذة أخرى، يتم إيقاف الفيديو تلقائياً وتغطية الشاشة بطبقة حماية تشويش زجاجية.
